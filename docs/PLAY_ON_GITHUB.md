# العب خبصة على GitHub مع أصحابك (ببلاش)

اللعبة بتشتغل على **GitHub Codespaces**، وهو سيرفر صغير بتعطيك إياه GitHub ببلاش. إنت بتشغّله لما بدكم تلعبوا، وبتبعت الرابط لأصحابك. أصحابك **ما بدهم حساب GitHub**، بيفتحوا الرابط من الموبايل أو الكمبيوتر وبيلعبوا.

## أول مرة (5 دقايق)
1. افتح المستودع: https://github.com/mtq-0/khabsa
2. اكبس الزر الأخضر **Code** ← تبويب **Codespaces** ← **Create codespace on main**.
   - أو افتح هالرابط مباشرة: https://codespaces.new/mtq-0/khabsa?quickstart=1
3. استنى 3 لـ 5 دقايق، لأنه أول مرة بنزّل وبيبني اللعبة.
4. تحت بالـ Terminal رح يطلع:
   ```
   ✅ خبصة شغالة! ابعت هالرابط لأصحابك:
      https://xxxxx-3000.app.github.dev
   ```
5. **انسخ الرابط وابعته لأصحابك على واتساب.** وإنت كمان افتحه والعبوا.

> إذا طلعت رسالة إنه ما قدر يخلي الرابط عام: افتح تبويب **PORTS** تحت، واكبس كليك يمين على `3000` ← **Port Visibility** ← **Public**.

> أول ما حدا يفتح الرابط ممكن تطلعله صفحة تحذير من GitHub بتقول إنه هاد موقع تجريبي. بيكبس **Continue** وبتفتح اللعبة.

## كل مرة بدكم تلعبوا
1. ادخل على https://github.com/codespaces
2. اكبس على الـ codespace تبع `khabsa`، وبيشتغل لحاله. اللعبة بتشتغل تلقائياً، و**الرابط نفسه ما بيتغيّر**.
3. لما تخلصوا، ارجع لنفس الصفحة واكبس **⋯ ← Stop codespace** عشان توفّر ساعاتك المجانية.

الحسابات والنقاط والإنجازات بتضل محفوظة بين المرات.

## مهم تعرفه
- **الخطة المجانية فيها 60 ساعة لعب بالشهر** على الجهاز الصغير (2-core)، وهاي كافية لسهرات كثير.
- **GitHub بيطفّي الـ codespace إذا ما لمسته 30 دقيقة**، حتى لو أصحابك عم يلعبوا، لأنه بيحسب الحركة جوّا الـ codespace بس. الحل: من https://github.com/settings/codespaces غيّر **Default idle timeout** لـ **240 دقيقة**.
- إذا انطفى بنص اللعب، شغّله من جديد. الغرفة والرابط بيرجعوا زي ما كانوا خلال 30 دقيقة.
- **إنت المدير:** من https://github.com/settings/codespaces ← **Secrets** ← **New secret**:
  - **Name:** `ADMIN_EMAILS`
  - **Value:** إيميلك
  - **Repository access:** اختار `mtq-0/khabsa`

  أعد تشغيل الـ codespace، وسجّل حساب باللعبة بنفس الإيميل، بتطلعلك لوحة الإدارة.
- **الصوت (اختياري):** اعمل حساب ببلاش على cloud.livekit.io، وضيف بنفس الطريقة ثلاث secrets:
  - `LIVEKIT_URL`
  - `LIVEKIT_API_KEY`
  - `LIVEKIT_API_SECRET`

  بدونهم الشات الكتابي بيشتغل عادي، وبتقدروا تحكوا على مكالمة واتساب.

## إذا صار في مشكلة
| المشكلة | الحل |
|---|---|
| الرابط بيطلع "404" أو صفحة GitHub | اللعبة لسا عم تشتغل، استنى دقيقة. أو اكتب بالـ Terminal: `bash scripts/codespace-start.sh` |
| أصحابي بيطلبلهم تسجيل دخول GitHub | الرابط مش عام: تبويب **PORTS** ← كليك يمين على 3000 ← **Port Visibility** ← **Public** |
| بدي أشوف شو صار | بالـ Terminal: `tail -50 data/server.log` |
| خلصت الساعات المجانية | بترجع أول الشهر، أو انشرها على Render ببلاش (docs/FREE_HOSTING.md) |
